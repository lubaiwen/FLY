# 无人机共享充电机巢管理系统

基于 **GAT-PPO（图注意力网络 + 近端策略优化）** 的智能调度系统，实现无人机与共享机巢的最优匹配与路径规划。

## 核心算法

### GAT-PPO 智能匹配

系统采用 **图注意力网络 (GAT)** 结合 **近端策略优化 (PPO)** 进行无人机-机巢最优匹配：

1. **图注意力网络 (GAT)**：将无人机和机巢建模为图节点，通过注意力机制学习节点间的交互关系
2. **PPO策略优化**：基于强化学习优化匹配策略，最大化全局调度效率
3. **贪心回退算法**：当GAT-PPO不可用时，使用基于距离、电量、容量的多因子评分进行贪心匹配

### 路径规划

- **直线路径**：两点间最短路径
- **折线路径**：基于障碍物避让的多航点路径
- **曲线路径**：平滑曲线路径（贝塞尔曲线）

## 快速开始

### 环境要求

- Node.js 18+
- Python 3.9+
- npm 或 yarn

### 后端启动

```bash
cd drone-nest-backend
npm install
npm start
# 服务运行在 http://localhost:3000
```

### 前端启动

```bash
cd drone-nest-management
npm install
npm run dev
# 服务运行在 http://localhost:5173
```

### 配置高德地图

在 `drone-nest-management/.env` 中配置高德地图密钥：

```
VITE_AMAP_KEY=你的高德地图Key
VITE_AMAP_SECURITY_CODE=你的安全密钥
```

## 技术栈

### 前端
- **框架**：Vue 3 + Composition API
- **构建**：Vite
- **UI组件**：Element Plus
- **状态管理**：Pinia
- **图表**：ECharts
- **地图**：高德地图 JSAPI 2.0（3D视图）
- **样式**：SCSS + 毛玻璃主题

### 后端
- **运行时**：Node.js 18+
- **框架**：Express
- **实时通信**：WebSocket
- **认证**：JWT
- **数据存储**：内存存储（MemoryStore）/ MySQL

### 算法引擎
- **语言**：Python 3.9+
- **深度学习**：PyTorch + PyTorch Geometric
- **算法**：GAT图注意力网络 + PPO近端策略优化
